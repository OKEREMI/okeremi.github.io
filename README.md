# Globe Rush website

A static site for GitHub Pages: home page, privacy policy, terms, 404, app-ads.txt, robots.txt and sitemap.
No build step, no trackers, and fonts are self-hosted.

## Publish (free)
1. Create a public GitHub repo named exactly `okeremi.github.io` (your username + .github.io).
   It must be this name: app-ads.txt only works at the root of the site.
2. Put all these files at the top of the repo and push.
3. Repo Settings > Pages > Source: "Deploy from a branch", branch `main`, folder `/ (root)`.
4. After a minute the site is live at https://okeremi.github.io/

## Fill in before launch
- privacy.html and terms.html: every [BRACKET] item, then have the lawyer review both. Remove the "Draft" box only after that.
- app-ads.txt: paste the line AppLovin gives you (Account > app-ads.txt).
- index.html #download: replace "Launching soon" with the Google Play link.
- If you buy a domain later, update canonical, og:image, robots.txt and sitemap.xml.
